# capacitor-android (vendored)

This is a verbatim copy of the Gradle library project shipped inside the `@capacitor/android`
npm package (`node_modules/@capacitor/android/capacitor`), version **8.5.1** — the version
pinned in the repository root `package.json`. Only `README.md` was added; nothing else in this
directory is hand-edited.

## Why it is committed

`capacitor.settings.gradle` is generated by `cap sync` and points `:capacitor-android` at a path
inside `node_modules`. That path exists only after a JS install, so the Android project could not
be opened and built from a fresh `git clone` without first installing Node, pnpm and the
dependencies. `android/settings.gradle` therefore falls back to this copy whenever the generated
`node_modules` path does not resolve, which makes `android/` a self-contained Gradle project:
clone, open in Android Studio, sync, run.

When the toolchain *is* installed, `settings.gradle` still uses the generated
`capacitor.settings.gradle` unchanged, so `cap sync` remains the source of truth.

## Refreshing it

After changing the `@capacitor/android` version in `package.json` (and installing), replace the
contents of this directory and keep the version note above in sync:

```sh
rm -rf android/capacitor-android
mkdir -p android/capacitor-android
cp -RL node_modules/@capacitor/android/capacitor/. android/capacitor-android/
cp -L node_modules/@capacitor/android/LICENSE android/capacitor-android/LICENSE
# restore this file, then commit
```

Adding a Capacitor *plugin* introduces a second `node_modules` Gradle project in
`capacitor.settings.gradle`. Vendor it the same way and extend the fallback branch in
`android/settings.gradle`, otherwise a clean clone will not configure.
